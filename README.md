## 判断一台机器是不是真住宅IP，看四个硬指标

**ASN 归属、是否原生、是否静态独享、纯净度**，四项里有一项不对，这台机器的价值就打折。下面拆开讲。

**ASN 归属：ISP 还是 Hosting。** TikTok 判断账号网络环境时，会看 IP 的 ASN（自治系统编号）属于家宽运营商还是机房。这个判断影响三件事：注册流程、初始流量配额、风控敏感度。家宽 ISP 网络用安卓设备注册通常能跳过邮箱验证，机房 Hosting 网络一般要走验证；平台给两类网络的基础推流系数不同；机房 IP 因为历史上被大量用于刷量、爬虫，天然背更高的风险标签。有服务商公布过对比测试，同一套视频模板，ISP 住宅网络的新号初始播放大约是机房网络的两倍，不过这是商家单方面的测试口径，没有第三方复现，只能当定性参考。

**是否原生：IP 注册地要和服务器实际所在国家一致。** 做澳洲区 TikTok，用一台物理在澳洲、IP 注册地也在澳洲的机器最稳；IP 归属地和服务器位置对不上，地理层面就有矛盾，推流时会吃亏。

**是否静态独享。** 一个账号绑定一个固定IP，别用会轮换的动态IP。"同账号多IP登录"本身就是风控关注的行为。这也是住宅IP **VPS** 和住宅**代理**的核心区别：VPS 是你独享一台服务器加一个固定IP，代理通常是共享IP池、IP 会轮换、多人共用同一段，养号这种需要长期绑定固定IP的场景不合适。

**纯净度自查。** 拿到IP后，用 Scamalytics 或 IPQS 输入地址查欺诈分值，越接近 0 越好。这一步不依赖任何商家说辞，是全文唯一你能自己复核的质量指标，买前买后都建议跑一遍。

四项之外还有一条地区匹配原则：目标市场在哪，就选哪里的节点。TikTok 各地区算法和推流池相互独立，用香港IP跑美区、用美国IP跑澳洲区，会因地理归属矛盾被压制推荐。这条原则比任何"哪个国家IP更好"的说法都实用。

## FAQ

**Q：住宅 IP VPS 和住宅代理 IP 是一回事吗？**
不是。VPS 是独享服务器 + 固定住宅 IP，IP 固定、只有你用；住宅代理多是共享 IP 池、IP 会轮换。养号需要账号长期绑定同一个 IP，VPS 更合适。

**Q：一台机器能挂几个 TikTok 号？**
分场景：直播账号严格一对一；短视频矩阵在内容差异明显、设备指纹分开的前提下，业内常见上限是 5 个左右。超过密度，账号之间的关联风险会上升。

**Q：怎么验证买到的 IP 是不是真住宅？**
拿到 IP 后用 Scamalytics 或 IPQS 查，看 ASN 归属是 ISP 还是 Hosting、欺诈分是否接近 0。这比看商家宣传页可靠。

**Q：做澳洲区，能用美国 IP 跑吗？**
能连上，但效果会打折。IP 归属地和目标市场不一致，推流机制里地理归属这一项就吃亏。做哪个市场，就用哪个市场的本地 IP。

**Q：中国大陆访问需要额外配中转吗？**
看节点。韩国、台湾这类标注三网直连的免中转；日本、澳洲、欧洲多数节点视运营商需要中转。下单前对着"中转提示"那一列和自己的宽带运营商确认。
